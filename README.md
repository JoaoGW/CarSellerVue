<h1 align="center">🚗 CarSellerVue</h1>

<p align="center">
  Uma aplicação web desenvolvida com Vue.js 3 para facilitar a venda de automóveis de diversos tipos e faixas de preço.
  <br />
  O projeto visa oferecer uma plataforma intuitiva e responsiva para vendedores e compradores de veículos.
</p>

## 📦 Instalação

Siga os passos abaixo para rodar o projeto localmente:

No bash:
### Clone o repositório
git clone https://github.com/JoaoGW/CarSellerVue.git

### Acesse o diretório do projeto
cd CarSellerVue

### Instale as dependências
npm install

### Inicie o servidor de desenvolvimento
npm run serve

---

## 🧪 Testes
Para executar os testes e verificar a qualidade do código, utilize:

npm run lint
